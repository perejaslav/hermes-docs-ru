# Apple Notes
Используйте `memo` для управления Apple Notes прямо из терминала. Заметки синхронизируются между всеми устройствами Apple через iCloud.
## Предварительные требования[​](<#prerequisites> "Прямая ссылка на Предварительные требования")
  * **macOS** с Notes.app
  * Установка: `brew tap antoniorodr/memo && brew install antoniorodr/memo/memo`
  * Предоставьте доступ к управлению Notes.app при запросе (Системные настройки → Конфиденциальность → Автоматизация)


## Когда использовать[​](<#when-to-use> "Прямая ссылка на Когда использовать")
  * Пользователь просит создать, просмотреть или найти заметки Apple Notes
  * Сохранение информации в Notes.app для доступа с разных устройств
  * Организация заметок в папки
  * Экспорт заметок в Markdown/HTML


## Когда НЕ использовать[​](<#when-not-to-use> "Прямая ссылка на Когда НЕ использовать")
  * Управление хранилищем Obsidian → используйте навык `obsidian`
  * Bear Notes — отдельное приложение (не поддерживается здесь)
  * Быстрые заметки только для агента → используйте инструмент `memory`


## Краткий справочник[​](<#quick-reference> "Прямая ссылка на Краткий справочник")
### Просмотр заметок[​](<#view-notes> "Прямая ссылка на Просмотр заметок")
[code]
    memo notes                        # Список всех заметок
    memo notes -f "Имя папки"         # Фильтр по папке
    memo notes -s "запрос"            # Поиск заметок (нечёткий)
    
[/code]
### Создание заметок[​](<#create-notes> "Прямая ссылка на Создание заметок")
[code]
    memo notes -a                     # Интерактивный редактор
    memo notes -a "Название заметки"  # Быстрое добавление с названием
    
[/code]
### Редактирование заметок[​](<#edit-notes> "Прямая ссылка на Редактирование заметок")
[code]
    memo notes -e                     # Интерактивный выбор для редактирования
    
[/code]
### Удаление заметок[​](<#delete-notes> "Прямая ссылка на Удаление заметок")
[code]
    memo notes -d                     # Интерактивный выбор для удаления
    
[/code]
### Перемещение заметок[​](<#move-notes> "Прямая ссылка на Перемещение заметок")
[code]
    memo notes -m                     # Перемещение заметки в папку (интерактивно)
    
[/code]
### Экспорт заметок[​](<#export-notes> "Прямая ссылка на Экспорт заметок")
[code]
    memo notes -ex                    # Экспорт в HTML/Markdown
    
[/code]
## Ограничения[​](<#limitations> "Прямая ссылка на Ограничения")
  * Нельзя редактировать заметки, содержащие изображения или вложения
  * Интерактивные подсказки требуют доступа к терминалу (при необходимости используйте pty=true)
  * Только macOS — требуется Apple Notes.app


## Правила[​](<#rules> "Прямая ссылка на Правила")
  1. Предпочитайте Apple Notes, когда пользователю нужна синхронизация между устройствами (iPhone/iPad/Mac)
  2. Используйте инструмент `memory` для внутренних заметок агента, которые не нужно синхронизировать
  3. Используйте навык `obsidian` для управления знаниями в формате Markdown
