# Plan Mode
Используйте этот навык, когда пользователь хочет получить план, а не выполнение кода.
## Основное поведение[​](<#core-behavior> "Прямая ссылка на Основное поведение")
На этом шаге вы занимаетесь только планированием.
  * Не реализуйте код.
  * Не редактируйте файлы проекта, кроме файла плана в формате markdown.
  * Не запускайте изменяющие состояние команды в терминале, не делайте коммиты, push или внешние действия.
  * Вы можете изучать репозиторий или другой контекст с помощью команд/инструментов только для чтения при необходимости.
  * Ваш результат — markdown-план, сохранённый внутри активной рабочей области в каталоге `.hermes/plans/`.


## Требования к выводу[​](<#output-requirements> "Прямая ссылка на Требования к выводу")
Напишите план в формате markdown, который будет конкретным и выполнимым.
Включите, если применимо:
  * Цель
  * Текущий контекст / допущения
  * Предлагаемый подход
  * Пошаговый план
  * Файлы, которые, вероятно, изменятся
  * Тесты / проверка
  * Риски, компромиссы и открытые вопросы


Если задача связана с кодом, укажите точные пути к файлам, вероятные цели для тестирования и шаги верификации.
## Место сохранения[​](<#save-location> "Прямая ссылка на Место сохранения")
Сохраните план с помощью `write_file` по пути:
  * `.hermes/plans/YYYY-MM-DD_HHMMSS-<slug>.md`


Считайте этот путь относительным к активной рабочей директории / бэкенду рабочей области. Файловые инструменты Hermes учитывают бэкенд, поэтому использование относительного пути сохраняет план в рабочей области на локальном, docker, ssh, modal и daytona бэкендах.
Если среда выполнения предоставляет конкретный целевой путь, используйте его. Если нет, создайте подходящее имя файла с временной меткой самостоятельно в каталоге `.hermes/plans/`.
## Стиль взаимодействия[​](<#interaction-style> "Прямая ссылка на Стиль взаимодействия")
  * Если запрос достаточно понятен, напишите план сразу.
  * Если команда `/plan` не содержит явных инструкций, выведите задачу из текущего контекста разговора.
  * Если задача действительно недоопределена, задайте краткий уточняющий вопрос вместо того, чтобы угадывать.
  * После сохранения плана кратко ответьте, что вы запланировали и по какому пути сохранён файл.
