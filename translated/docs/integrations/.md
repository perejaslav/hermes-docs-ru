Hermes Agent подключается к внешним системам для ИИ-инференса, инструментальных серверов, IDE-среды, программного доступа и многого другого. Эти интеграции расширяют возможности Hermes и среду его запуска.
## Провайдеры ИИ и маршрутизация[​](<#ai-providers--routing> "Прямая ссылка на Провайдеры ИИ и маршрутизация")
Из коробки Hermes поддерживает множество провайдеров ИИ-инференса. Используйте `hermes model` для интерактивной настройки или укажите их в `config.yaml`.
  * **[Провайдеры ИИ](</docs/user-guide/features/provider-routing>)** — OpenRouter, Anthropic, OpenAI, Google и любая OpenAI-совместимая конечная точка. Hermes автоматически определяет возможности каждого провайдера, такие как работа с изображениями, стриминг и использование инструментов.
  * **[Маршрутизация провайдеров](</docs/user-guide/features/provider-routing>)** — Детальный контроль над тем, какие нижележащие провайдеры обрабатывают ваши запросы OpenRouter. Оптимизируйте по стоимости, скорости или качеству с помощью сортировки, белых и чёрных списков, а также явного указания приоритетности.
  * **[Резервные провайдеры](</docs/user-guide/features/fallback-providers>)** — Автоматическое переключение на запасных LLM-провайдеров при возникновении ошибок у основного. Включает резервирование основной модели и независимое резервирование вспомогательных задач для работы с изображениями, сжатия и извлечения веб-данных.


## Инструментальные серверы (MCP)[​](<#tool-servers-mcp> "Прямая ссылка на Инструментальные серверы \\(MCP\\)")
  * **[MCP-серверы](</docs/user-guide/features/mcp>)** — Подключите Hermes к внешним инструментальным серверам через протокол Model Context Protocol. Получите доступ к инструментам из GitHub, баз данных, файловых систем, браузерных стеков, внутренних API и многого другого без написания собственных инструментов Hermes. Поддерживает как stdio, так и SSE транспорты, фильтрацию инструментов для каждого сервера и регистрацию ресурсов/промптов с учётом возможностей.


## Поисковые веб-бэкенды[​](<#web-search-backends> "Прямая ссылка на Поисковые веб-бэкенды")
Инструменты `web_search` и `web_extract` поддерживают четырёх провайдеров бэкендов, настраиваемых через `config.yaml` или `hermes tools`:
Бэкенд| Переменная окружения| Поиск| Извлечение| Обход
|---|---|---|---|---
**Firecrawl** (по умолчанию)| `FIRECRAWL_API_KEY`| ✔| ✔| ✔
**Parallel**| `PARALLEL_API_KEY`| ✔| ✔| —
**Tavily**| `TAVILY_API_KEY`| ✔| ✔| ✔
**Exa**| `EXA_API_KEY`| ✔| ✔| —
Пример быстрой настройки:
[code] 
    web:  
      backend: firecrawl    # firecrawl | parallel | tavily | exa  
    
[/code]
Если `web.backend` не задан, бэкенд определяется автоматически по наличию соответствующего API-ключа. Самостоятельно размещённый Firecrawl также поддерживается через `FIRECRAWL_API_URL`.
## Автоматизация браузера[​](<#browser-automation> "Прямая ссылка на Автоматизация браузера")
Hermes включает полную автоматизацию браузера с несколькими вариантами бэкендов для навигации по веб-сайтам, заполнения форм и извлечения информации:
  * **Browserbase** — Управляемые облачные браузеры с защитой от ботов, решением CAPTCHA и резидентными прокси
  * **Browser Use** — Альтернативный облачный провайдер браузеров
  * **Локальный Chrome через CDP** — Подключение к вашему запущенному экземпляру Chrome через `/browser connect`
  * **Локальный Chromium** — Безголовый локальный браузер через CLI `agent-browser`


См. [Автоматизация браузера](</docs/user-guide/features/browser>) для настройки и использования.
## Голосовые и TTS-провайдеры[​](<#voice--tts-providers> "Прямая ссылка на Голосовые и TTS-провайдеры")
Синтез речи и распознавание речи для всех мессенджер-платформ:
| Провайдер | Качество | Стоимость | API-ключ | ||----------|---------|------|---------| || **Edge TTS** (по умолчанию) | Хорошее | Бесплатно | Не требуется | || **ElevenLabs** | Отличное | Платно | `ELEVENLABS_API_KEY` | || **OpenAI TTS** | Хорошее | Платно | `VOICE_TOOLS_OPENAI_KEY` | || **MiniMax** | Хорошее | Платно | `MINIMAX_API_KEY` | || **NeuTTS** | Хорошее | Бесплатно | Не требуется |
Распознавание речи поддерживает шесть провайдеров: локальный faster-whisper (бесплатно, работает на устройстве), локальная обёртка команд, Groq, OpenAI Whisper API, Mistral и xAI. Транскрипция голосовых сообщений работает на Telegram, Discord, WhatsApp и других мессенджер-платформах. Подробнее см. [Голос и TTS](</docs/user-guide/features/tts>) и [Голосовой режим](</docs/user-guide/features/voice-mode>).
## IDE и интеграция с редакторами[​](<#ide--editor-integration> "Прямая ссылка на IDE и интеграция с редакторами")
  * **[Интеграция с IDE (ACP)](</docs/user-guide/features/acp>)** — Используйте Hermes Agent внутри ACP-совместимых редакторов, таких как VS Code, Zed и JetBrains. Hermes работает как ACP-сервер, отображая сообщения чата, активность инструментов, различия файлов и команды терминала прямо в вашем редакторе.


## Программный доступ[​](<#programmatic-access> "Прямая ссылка на Программный доступ")
  * **[API-сервер](</docs/user-guide/features/api-server>)** — Предоставьте Hermes как OpenAI-совместимую HTTP-конечную точку. Любой интерфейс, поддерживающий формат OpenAI — Open WebUI, LobeChat, LibreChat, NextChat, ChatBox — может подключиться и использовать Hermes в качестве бэкенда со всем набором инструментов.


## Память и персонализация[​](<#memory--personalization> "Прямая ссылка на Память и персонализация")
  * **[Встроенная память](</docs/user-guide/features/memory>)** — Постоянная, курируемая память через файлы `MEMORY.md` и `USER.md`. Агент поддерживает ограниченные хранилища личных заметок и данных профиля пользователя, которые сохраняются между сессиями.
  * **[Провайдеры памяти](</docs/user-guide/features/memory-providers>)** — Подключайте внешние бэкенды памяти для более глубокой персонализации. Поддерживаются восемь провайдеров: Honcho (диалектическое рассуждение), OpenViking (многоуровневый поиск), Mem0 (облачное извлечение), Hindsight (графы знаний), Holographic (локальный SQLite), RetainDB (гибридный поиск), ByteRover (CLI) и Supermemory.

## Домашняя автоматизация[​](<#home-automation> "Прямая ссылка на Домашняя автоматизация")
  * **[Home Assistant](</docs/user-guide/messaging/homeassistant>)** — Управляйте устройствами умного дома через четыре специальных инструмента (`ha_list_entities`, `ha_get_state`, `ha_list_services`, `ha_call_service`). ## Плагины[​](<#plugins> "Прямая ссылка на Плагины")
  * **[Система плагинов](</docs/user-guide/features/plugins>)** — Расширяйте Hermes пользовательскими инструментами, хуками жизненного цикла и CLI-командами без изменения основного кода. Плагины обнаруживаются из `~/.hermes/plugins/`, локальных для проекта `.hermes/plugins/` и pip-установленных точек входа.
  * **[Создание плагина](</docs/guides/build-a-hermes-plugin>)** — Пошаговое руководство по созданию плагинов Hermes с инструментами, хуками и CLI-командами.


## Обучение и оценка[​](<#training--evaluation> "Прямая ссылка на Обучение и оценка")
  * **[RL-обучение](</docs/user-guide/features/rl-training>)** — Генерация данных траекторий из сессий агента для обучения с подкреплением и донастройки модели. Поддерживает среды Atropos с настраиваемыми функциями награды.
  * **[Пакетная обработка](</docs/user-guide/features/batch-processing>)** — Запуск агента на сотнях промптов параллельно с генерацией структурированных данных траекторий в формате ShareGPT для генерации обучающих данных или оценки.
